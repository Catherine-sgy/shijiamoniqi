# 百年宗谱 📜

一款纯原创的**古代家族模拟养成**网页游戏：一纸宗谱，代代相传。读书科举、置田开铺、娶妻生子、送女入宫、当清官造福乡梓——把一个家族从布衣种田带成名门世家。

▶ **点开即玩**：本页面即游戏（单文件，无需安装，不联网也能玩，存档保存在本机浏览器）

## 玩法一眼看

- 📚 **科举入仕**：童试 → 乡试（解元）→ 会试（会元）→ 殿试（状元 / 榜眼 / 探花 / 传胪），金殿传胪红色喜报
- 🏠 **家族经营**：置田收租、开铺经商、钱庄存借、族学延师、宅院扩建
- 👪 **人丁兴旺**：娶妻纳媳、招赘留家、生育率与难产、立嗣传位、字辈传承
- 💘 **人际高门**：结交名帖、琅琊王氏等五姓高门（刷好感、联姻、举荐升官）
- 🏯 **宫廷线**：送女入宫为宫女 / 选秀为妃，诞育皇嗣，阖宫同庆；高位妃嫔逢年过节有宫中赏赐
- ⚖️ **清官之路**：唯政绩论升迁，修堤劝农、平冤赈疫，拒贿守正，靠政绩步步升迁

## 操作

- 每月 2 点精力，点“度月”推进时间，“度年”快速推进一年；行动区可设自动（复刻上月 / 精力全投一项）
- 右上角可**导出 / 导入存档**（换手机、换浏览器不丢档）
- 手机浏览器打开后用"添加到主屏幕"，即有 App 般的全屏体验
